# THE HAUNTED VILLA
**YOUR NIGHTMARE BEGINS NOW**

A third-person 3D horror game that runs in the browser (Three.js r147).
Five friends shelter from a storm in an abandoned villa. The villa belongs to Chhaya Rani,
who has been waiting for her son Khokon since 1931. Escape across 5 levels, learn her story
from 15 torn diary pages, and reach one of three endings.
Languages: English, हिंदी, বাংলা (chosen once in the menu).

## Controls (laptop)
| Key | Action |
|---|---|
| Mouse | Look around |
| W A S D | Move |
| Shift | Run |
| Left click / Space | Attack (God's Knife, crowbar) |
| Q / Right click | Throw holy water |
| F | Torch on / off |
| U | UV light (shows hidden writing) |
| C | Camcorder with night vision (shows spirits) |
| E | Use: sit, hide, look outside, piano, safe, spirit board, free a friend |
| Hold Space (while hiding) | Hold your breath |
| 1 - 8 | Piano keys |
| H | Ask friends for a hint |
| B | Use a bandage |
| M | Mute |
| P / Esc | Pause |

A gamepad and touch screens also work.

## Host it on GitHub Pages (free)
1. Unzip this file.
2. On GitHub, create a new **public** repository, for example `the-haunted-villa`.
3. Click **Add file > Upload files** and drag in `index.html`, `README.md` and `.nojekyll`, then **Commit changes**.
4. Open **Settings > Pages**. Under **Build and deployment**, choose **Deploy from a branch**, pick the `main` branch and the `/ (root)` folder, then **Save**.
5. After a minute or two the game is live at `https://<your-username>.github.io/the-haunted-villa/`.

## GitHub Pages पर होस्ट करें (हिंदी)
1. ZIP को unzip करें।
2. GitHub पर एक नई **public** repository बनाएँ, जैसे `the-haunted-villa`।

4. **Settings > Pages** में **Deploy from a branch** चुनें, branch `main` और folder `/ (root)` चुनकर **Save** करें।
5. एक-दो मिनट बाद गेम `https://<आपका-username>.github.io/the-haunted-villa/` पर चलने लगेगा।
